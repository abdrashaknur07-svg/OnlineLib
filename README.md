# 📚 OnlineLibrary — Онлайн кітапхана жүйесі

## Жоба туралы

OnlineLibrary — PHP және MySQL технологиялары арқылы
әзірленетін онлайн кітапхана веб-қосымшасы.

Жүйе пайдаланушыларға кітаптарды іздеуге,
қарауға және кітапхана қорымен жұмыс істеуге мүмкіндік береді.

## Жобаның мақсаты

Кітапхана жұмысын автоматтандыру және
пайдаланушыларға кітаптар туралы ақпаратты
ыңғайлы түрде ұсыну.

## Қолданылатын технологиялар

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git және GitHub

## Негізгі мүмкіндіктер

1. Пайдаланушыны тіркеу
2. Жүйеге кіру және шығу
3. Кітаптар каталогын қарау
4. Кітаптарды атауы бойынша іздеу
5. Автор бойынша сүзу
6. Жаңа кітап қосу
7. Кітап мәліметтерін өзгерту
8. Кітаптарды жою
9. Пайдаланушы профилі

## Сайт беттері

- index.php — басты бет
- books.php — кітаптар каталогы
- login.php — жүйеге кіру
- register.php — тіркелу
- profile.php — жеке кабинет
- add_book.php — кітап қосу
- edit_book.php — кітапты өңдеу

## Дерекқор құрылымы

### 1. users
- id — PRIMARY KEY
- name — пайдаланушы аты
- email — электрондық пошта
- password — құпиясөз хэші
- role — пайдаланушы рөлі

### 2. categories
- id — PRIMARY KEY
- name — санат атауы

### 3. books
- id — PRIMARY KEY
- title — кітап атауы
- author — автор
- category_id — FOREIGN KEY
- description — сипаттама
- created_at — қосылған уақыты

## Кестелер арасындағы байланыс

categories (1) → (N) books

Бір санатта бірнеше кітап болуы мүмкін.
